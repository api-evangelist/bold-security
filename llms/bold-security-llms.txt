# Bold Security

> Bold Security provides real-time, on-device (endpoint) data security. Its on-device AI classifies data interactions across every application in real time and detects and prevents user- and AI-agent-driven data exfiltration before sensitive data leaves the endpoint, without requiring policy configuration or cloud round-trips. Bold is ISO 27001 certified and SOC 2 compliant, and is a portfolio company of Bessemer Venture Partners.
